# dotfiles

```
dotfiles/
├── nvim/        # Neovim config  -> symlinked to ~/.config/nvim
├── ghostty/     # Ghostty config -> symlinked to ~/.config/ghostty/config
└── install.sh   # Fresh-machine bootstrap
```

## Fresh machine setup

```sh
git clone https://github.com/dhan0779/dotfiles.git ~/dotfiles
~/dotfiles/install.sh
```
